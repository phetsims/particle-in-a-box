# Particle in a Box - implementation notes

This simulation is part of the _Quantum Bound States_ suite of simulations.

The _Eigenstate_ screen is based on the _One Well_ screen in the _Quantum Bound States_ simulation, with the
following differences:
* Infinite Square only, no choices for quantum potential
* Independent accessible description at the screen summary level

The _Superposition_ screen is based on the _Superposition_ screen in the _Quantum Bound States_ simulation, with the
following differences:
* Infinite Square only, no choices for quantum potential
* Independent accessible description at the screen summary level

For further details, see [totality/quantium-bound-states/doc/implementation-notes.md](https://github.com/phetsims/totality/blob/main/quantum-bound-states/doc/implementation-notes.md).
